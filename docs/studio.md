# 作品可视化工作台

开发服务器运行时打开 http://127.0.0.1:3001/studio 。工作台只在本机开发模式开放，生产站点不提供编辑及上传功能。

- 顶部选择作品，中间显示真实作品页。
- 点击图层选择，拖动改变位置；双击文字直接编辑，或使用右侧文字输入框。
- 右侧可改位置、宽度、字号、旋转，替换图片、隐藏或恢复原始图层。
- 新增文字或图片放在选中内容之后；未选择时放在正文末尾。
- 支持撤销、重做、缩放，以及桌面和手机宽度预览。
- 点击「保存并同步」才会写入项目；独立作品页刷新后生效。离开或切换作品前请保存。

## 保存位置

`src/data/studio/projects.json` 是每个作品的可视化覆盖配置，上传图片保存在 `public/studio/`。这两处都应随代码一起提交 Git；工作台不会自动推送 GitHub。

`ProjectEditable` 给正文文字与图片分配由标签、原始文字/图片 alt 和重复序号构成的稳定标识。修改原有文案或图片 alt 的源代码时，需同步对应配置；仅重新排列原有内容不会改变它的标识。后续代码修改必须保留用户在 JSON 中的覆盖设置。

第一版基于网页现有文档流，拖动是相对位置调整，并不自动重排其他段落；大幅移动、增加或缩放内容后应检查手机与桌面两个预览。现有动画由原组件继续负责。该版本不提供 Figma 的矢量绘制、自动布局或多人协作。
